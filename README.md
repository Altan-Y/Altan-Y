## Featured project

### [AccessHub — Access Governance Dashboard](https://github.com/Altan-Y/access-governance-dashboard)

A privacy-safe PHP portfolio application for exploring access groups, job roles, owners and approvers. It includes permission-aware editing, prepared SQL statements, an audit trail, Docker support and a responsive dark mode.

> **Transparent portfolio note:** The public project is an independently rewritten demo inspired by real-world experience. The original production concept used LDAPS / Active Directory and a remote MySQL-compatible database. The public version uses fictional local accounts and SQLite / JSON so that no employer code, internal data or credentials are published.
